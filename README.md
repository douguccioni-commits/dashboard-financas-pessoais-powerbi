# 💰 Dashboard de Finanças Pessoais (Power BI)

Este projeto consiste em um dashboard completo para controle e visualização de finanças pessoais, desenvolvido no **Power BI**. O objetivo é transformar dados brutos em insights claros sobre patrimônio, dívidas, investimentos e fluxo de caixa mensal.

## 🚀 Funcionalidades e Visões

O dashboard está dividido em 3 visões principais, navegáveis através de botões no topo:

1.  **Início (Visão Geral):** Resumo do Saldo Total em conta, Receitas, Despesas, Evolução Mensal (gráfico de barras) e detalhamento de Investimentos (gráfico de cascata/treemap).
2.  **Investimentos:** Foco no patrimônio total, metas financeiras (Tabela de valores desejados) e acompanhamento do valor guardado por objetivo (gráfico de barras horizontais), além do saldo detalhado por instituição bancária.
3.  **Dívidas:** Controle do salário comprometido, saldo devedor total, total de parcelas mensais e comparativo entre o valor contratado e o valor a pagar (juros embutidos).

## 🛠️ Tecnologias e Técnicas Utilizadas

*   **Power BI Desktop:** Construção dos visuais e layout.
*   **Design UI/UX:** Interface em *Dark Mode* com paleta de cores personalizada (verde, azul e amarelo) para facilitar a leitura e dar um aspecto moderno.
*   **Linguagem DAX:** Criação de medidas complexas para os cálculos.
*   **Modelagem de Dados:** Estruturação das tabelas Fato e Dimensão.

## 📂 Como visualizar este projeto

Como o arquivo do Power BI (`.pbix`) contém os dados e o modelo, siga os passos abaixo:

1. Faça o download do arquivo `.pbix` disponível neste repositório.
2. Certifique-se de ter o **Power BI Desktop** instalado em sua máquina.
3. Abra o arquivo e navegue pelas abas.

## ⚠️ Nota sobre Privacidade de Dados

Os dados apresentados neste dashboard são **fictícios/anonimizados** para fins de demonstração de portfólio. Nenhuma informação bancária real ou dado sensível foi exposto.
